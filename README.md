## Selected engineering work

### [Parcel-Tracking System — Beacon + Gateway](https://tahiriii-ai.github.io/ta-embedded-solutions/projects/parcel-tracking-system.html)

Two ESP32 devices and a printable Beacon enclosure, developed from a client specification through manufacturing files.

**My role** — Schematic review, 4-layer PCB layout for both devices, verification, manufacturing output, and Beacon enclosure design.

- ESP32-C3 Beacon and ESP32-S3 Gateway with BLE and ESP-NOW connectivity.
- LiPo charging with power path, a switchable 5 V LED rail, USB protection, and antenna keep-outs.
- ERC and DRC checks before handoff, with KiCad projects, Gerbers, drill files, BOM, and placement files.
- Fusion 360 enclosure with STL, STEP, and drawings.

**Tools and hardware** · KiCad · Fusion 360 · ESP32-C3 · ESP32-S3

### [Multi-Radio IoT Gateway — 8-Layer PCB Layout](https://tahiriii-ai.github.io/ta-embedded-solutions/projects/multi-radio-gateway-layout.html)

A dense STM32H7 gateway with more than 400 components, five RF sections, and ten SMA feeds.

**My role** — PCB layout from a client-supplied schematic, including floor-planning, stackup, routing, antenna feeds, and clock distribution.

- Organized multiple radio sections and their board-edge antenna connections.
- Routed the board across eight layers.
- Case study includes routing views and KiCad DRC results.

**Tools and hardware** · KiCad · STM32H7 · Multilayer PCB · RF routing

### [ARC62 Load-Cell Controller — Reverse Engineering & Diagnostics](https://tahiriii-ai.github.io/ta-embedded-solutions/projects/arc62-loadcell-repair.html)

An undocumented STM32 controller investigated using the supplied PCB and BOM.

**My role** — Schematic reconstruction, diagnosis of four field issues, a corrected KiCad revision, and a repair guide.

- Rebuilt connectivity to make the undocumented board understandable.
- Investigated the reported symptoms using the reconstructed design.
- Documented corrections and repair steps.

**Tools and hardware** · KiCad · STM32F103 · HX711 · CAN

### [RejsaCAN v3.4 — Compact PCB Redesign](https://tahiriii-ai.github.io/ta-embedded-solutions/projects/rejsacan-v3-redesign.html)

An ESP32-S3 CAN node with approximately 80 components in a 30 × 50 mm footprint.

**My role** — PCB redesign from an existing open-source schematic.

- Integrated ESP32-S3, USB-C, a CAN transceiver, and microSD.
- Balanced component placement and routing within a constrained outline.

**Tools and hardware** · KiCad · ESP32-S3 · CAN · USB-C · microSD
